# Javan — Product Vision

> **One workspace. Everything connected.**

## Mission
Build a local-first, modular environment where individuals and organisations work across local files, email, cloud storage, web applications and AI agents without juggling disconnected tools.

Javan is **not another chatbot** and **not a replacement operating system**. It is a desktop workspace that integrates the tools users choose.

## Problems worth solving
1. Fragmented workflows: files, inboxes, cloud drives, IDEs and agents live in different apps.
2. Repetitive onboarding: moving computers means rebuilding preferences and connections.
3. Bundled complexity: people install large products whose features they don't need.
4. Opaque agent behaviour: agents can alter files or communicate externally with unclear permissions.
5. Uneven interoperability: local data and remote providers use incompatible interfaces.

## Product principles
- **Local-first and offline-capable.** Core functions work without a Javan account or internet.
- **Modular by default.** Core shell plus opt-in modules. Uninstalling a module does not silently delete user data.
- **Explainable automation.** Humans review what agents will read, modify, deploy or send.
- **Portable configuration.** Optional Javan Sync restores preferences and compatible modules, not automatically the user's entire data.
- **Provider neutrality.** Start with Codex, but define agent/provider interfaces instead of hardcoding one vendor.
- **Privacy and security.** Secret material is locally protected; remote AI transfer boundaries are explicit.
- **Human-scale design.** Explorer on the left, active canvas at centre, agents on the right; every panel is adjustable.

## Audiences
| Audience | Need | Javan approach |
|---|---|---|
| Individual developer | Code, previews, agent workflows, servers | Editor + Codex + SFTP/S3 modules |
| Independent professional | Email, documents and cloud files | Mail + storage + search |
| Creative studio | Visual previews and asset management | Canvas + storage + workspace layouts |
| Small business | Shared tasks, agents, approvals | Future Javan Teams |
| Enterprise | Governance, identity, audit and isolation | Future Javan Enterprise after hardening |

## Differentiation
Javan combines **select-your-own modules**, **visual workspace composition**, **cross-resource workflows**, **optional configuration recovery**, and **permissioned AI agents**. Each piece exists elsewhere; the intended value is making them work together coherently.

## Things we explicitly are not promising
- An OS-level universal drive for every provider on day one.
- Full offline copies of all cloud storage by default.
- Agent autonomy without approvals.
- Seamless reuse of platform-bound sign-in tokens across different machines.
- Complete compatibility with every browser extension or VS Code extension.
- Enterprise compliance certifications before independent audit.

## Product family
- **Javan Desktop** — native local-first workspace.
- **Javan Modules** — optional first-party integrations.
- **Javan Sync** — opt-in settings and module restoration.
- **Javan Teams** — future shared workspaces and agent workflows.
- **Javan Cloud** — optional backend services.
- **Javan Enterprise** — future governance and deployment options.
